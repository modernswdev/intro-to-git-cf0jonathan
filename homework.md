# Homework Reflection

## What I learned

I already knew the basics of Git and GitHub, but this lesson filled in the details that make the workflow feel professional. I have a clearer picture of the GitHub flow: create a branch, make focused changes, open a pull request, and use review to keep quality high. I also see how issues and project boards turn vague ideas into trackable work, and how a good README and clean commit messages help collaborators understand intent quickly.

**Highlights**
- Branches are not just for "big" features; they are a safe space for any experiment.
- Pull requests are a communication tool, not just a merge button.
- Markdown lets me structure ideas so others can scan and respond.

I'm most confused about what I don't know, if that makes sense. I am looking forward to learning as I go, finding problems, then finding the solution.
